## 1. Ringkasan Eksekutif

Fase V13.0-D mengimplementasikan lapisan navigasi dan ruang kerja referensi (`World OS Layer`) tanpa mengambil alih pemilik siklus hidup (`bootPage()`), tanpa memindahkan `<main id="main">` atau kanvas aktif, dan tanpa menambah request pada *initial page load*.

Empat komponen utama yang diselesaikan:

1. **Static World Index Endpoint (`/api/world-index.json`)**: Dihasilkan pada waktu build (`prerender = true`, `13.489 byte`) dari `WORLD_TERRITORIES` (`14` wilayah), koleksi `work` (`3` entri), koleksi `adr` (`13` rekam), koleksi `codex` (`6` catatan), dan `WORLD_COMMANDS` (`7` perintah).
2. **Global Command Palette (`CommandPalette.astro` + `command-palette.ts`)**: Berbasis elemen `<dialog id="world-command-dialog">` native pada *top layer* browser, melakukan *lazy fetch* `/api/world-index.json` hanya saat pertama kali dibuka (`Ctrl+K` / `Cmd+K`), menggunakan normalisasi query deterministik (`NFKC`, *control-character stripping*, *lowercase*, batas `100` karakter) dan pemeringkatan 5 tingkat, serta merender hasil menggunakan `document.createElement` dan `textContent` murni.
3. **Reference Tiling Dock (`ReferenceDock.astro` + `tiling-dock.ts`)**: Panel referensi samping khusus desktop (`@media (min-width: 1024px)`, pintasan `Alt+Enter`) yang memuat halaman statis *same-origin* di dalam `<iframe sandbox="" loading="lazy" referrerpolicy="same-origin">` tanpa izin eksekusi skrip (`allow-scripts` tidak diberikan).
4. **Workspace Status Indicator (`Header.astro`)**: Trigger ringkas pada header yang menampilkan wilayah aktif, status `PALETTE READY` / `INDEX LOADING` / `DOCK ACTIVE`, dan petunjuk `Ctrl+K`, tanpa mengarang metrik CPU/RAM/FPS palsu.

## 3. Daftar Command & Kebijakan Keamanan URL Dock

| Command Syntax | Aksi | Validasi & Integrasi |
|---|---|---|
| `:warp <known-territory>` | Navigasi ke wilayah dalam `WORLD_TERRITORIES` | Mencocokkan `id`, `path`, atau `searchTerms` terhadap allowlist; menolak URL eksternal/arbitrary |
| `:split open` | Membuka Reference Dock pada desktop (`>= 1024px`) | Memanggil `openReferenceDock()` dengan validasi `validateDockTargetUrl()` |
| `:split close` | Menutup Reference Dock | Memanggil `closeReferenceDock()` dan menghapus atribut `data-dock-open` |
| `:audio mute` | Mematikan suara antarmuka | Memanggil `setAudioMuted(true)` dari `src/scripts/core/audio-runtime.js` + sinkronisasi `#audio-toggle` |
| `:audio unmute` | Mengaktifkan suara antarmuka | Memanggil `setAudioMuted(false)` dari `src/scripts/core/audio-runtime.js` + sinkronisasi `#audio-toggle` |
| `:audio toggle` | Membalik status mute suara antarmuka | Menggunakan state tunggal `isAudioMuted()` dari `audio-runtime.js` |
| `:top` | Gulir halus ke bagian atas halaman | Memanggil `scrollToTarget(qs('#top') \|\| document.body)` |

## 6. Known Limitations (Format Standar Bagian 6.4)

1. **Iframe Reference Dock Tanpa Skrip (`sandbox=""`)**
   - **Ringkasan masalah:** Halaman yang dibuka di dalam Reference Dock dirender menggunakan `<iframe sandbox="">` tanpa `allow-scripts`, sehingga elemen yang memerlukan eksekusi JavaScript (seperti kanvas interaktif Chart.js atau filter klien) tampil dalam mode *server-rendered HTML fallback*.
   - **Dampak pengguna atau sistem:** Pengguna dapat membaca seluruh teks metodologi, rumus MathML statis, tabel bukti Codex, dan isi laporan ADR dengan aman, serta menggunakan tombol `Open full page ↗` bila memerlukan fitur interaktif penuh.
   - **Mengapa tidak diperbaiki pada fase ini:** Kontrak D.4.3 secara eksplisit menetapkan `<iframe sandbox="">` tanpa `allow-scripts` sebagai default paling aman untuk mencegah duplikasi lifecycle atau kebocoran skrip di dalam panel referensi.
   - **Status:** Non-blocker (sesuai desain keamanan D.4.3).
   - **Syarat penyelesaian:** Tidak diperlukan perubahan kecuali kelak disusun arsitektur sanitizer sub-pohon DOM khusus.
   - **File atau test terkait:** `src/components/layout/ReferenceDock.astro`, `src/scripts/global/tiling-dock.ts`, `scripts/test-v13-world-os.mjs`.
