## 1. Ringkasan Eksekutif

Fase V13.0-A membangun **The Engineering Records Vault** (`/archive/adr` dan `/archive/adr/[slug]`) untuk mengindeks dan menyajikan 13 laporan rekayasa historis (V10.3 hingga V12.3) sebagai koleksi Astro Content Layer yang tervalidasi pada waktu build. Seluruh berkas sumber historis di root proyek tetap utuh byte-for-byte tanpa perubahan. Proses sinkronisasi deterministik (`scripts/data/sync-adr-collection.mjs`) menghitung digest `SHA-256` dari raw source bytes sebelum melakukan normalisasi karakter U+2014 hanya pada salinan di `src/content/adr/*.md`.

## 5. Known Limitations

1. **Pembedaan Status Historis vs Verifikasi Saat Ini (`recordStatus`)**
   - **Ringkasan masalah:** Beberapa laporan historis (seperti `V10.5_EXPERIMENT_REPORT.md` dan `V11.0_IMPLEMENTATION_REPORT.md`) mencatat hasil eksperimen atau metrik Lighthouse pada saat versi tersebut diuji.
   - **Dampak pengguna atau sistem:** Pengguna dapat salah mengartikan metrik historis sebagai klaim performa real-time V13.0 bila label status tidak dibedakan.
   - **Mengapa tidak diubah di sumber:** Berkas sumber historis bersifat immutable dan tidak boleh diedit.
   - **Status Blocker:** Non-blocker (telah dimitigasi melalui badge `superseded`, `historical`, dan `implemented-reported` pada metadata ADR).
   - **Syarat penyelesaian:** Dipertahankan sebagai prinsip kurasi permanen.
   - **File/Test terkait:** `src/lib/adr-taxonomy.ts`, `src/pages/archive/adr/index.astro`, `scripts/test-v13-adr.mjs`.

2. **Format Teks Polos pada `V10.5_FINAL_VERIFICATION.txt`**
   - **Ringkasan masalah:** Berkas sumber `V10.5_FINAL_VERIFICATION.txt` adalah berkas `.txt` pendek (6 baris) tanpa struktur heading Markdown `##`.
   - **Dampak pengguna atau sistem:** Halaman detail `/archive/adr/v10-5-final-verification` tidak memiliki daftar isi (TOC) samping karena tidak ada heading `h2`/`h3`.
   - **Mengapa tidak diubah di sumber:** Isi sumber asli tidak boleh dimodifikasi atau ditambah heading buatan.
   - **Status Blocker:** Non-blocker (komponen detail ADR secara otomatis menampilkan fallback `Dokumen ini tidak memiliki sub-heading H2/H3` dengan rapi).
   - **Syarat penyelesaian:** Tidak memerlukan perubahan.
   - **File/Test terkait:** `src/pages/archive/adr/[slug].astro`.

## 6. Pernyataan Kepatuhan Universal Protocol

- **Zero Git / Zero VCS:** Tidak ada perintah `git`, `gh`, atau operasi version control lain yang dieksekusi selama Fase A.
- **Imutabilitas Sumber Historis:** Seluruh 13 berkas sumber historis di root proyek memiliki digest `SHA-256` yang identik 100% antara snapshot preflight (`v13-work/snapshots/phase-a/run-1/manifest.sha256`) dan pasca-implementasi.
- **Zero New Em-Dash (U+2014):** Seluruh berkas baru dan modifikasi Fase A bebas dari karakter U+2014.
- **Safe DOM:** Tidak ada penggunaan `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `eval`, atau `new Function`.
