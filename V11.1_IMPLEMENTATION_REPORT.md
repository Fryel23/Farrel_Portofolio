### OGL controller (`src/scripts/hero-webgl/index.js` — CREATE)

- Scheduling: 2×rAF → `requestIdleCallback` (timeout 1200ms; fallback setTimeout 300ms) — tanpa `window.onload`/network idle; semua scheduled handle bisa dibatalkan.
- Setelah setiap `await`: re-check guard (cancelled, isConnected, MQ, reduced, state) — hasil import terlambat **tidak pernah** membuat context.
- Renderer: `alpha:true`, `antialias:true`, `dpr = min(devicePixelRatio, 1.5)`, `premultipliedAlpha:false`, `powerPreference:'default'`; `gl.clearColor(0,0,0,0)`; validasi `renderer.gl` sebelum resource lain.
- Ukuran dari `getBoundingClientRect()` wrapper (bukan window) + `ResizeObserver` (fallback window.resize) dengan zero-size guard, update DPR saat zoom.
- Satu RAF loop (Vessel + particles), pause saat wrapper offscreen (`IntersectionObserver` 0.01) dan saat `document.hidden`; resume tanpa jump (animasi berbasis `uTime` periodik).
- State machine: `idle → waiting → loading → ready | fallback`; dispose final/temporary (§G).

## E. WebGL Technical Details

- **OGL version**: 1.0.11 (npm; satu-satunya dependency baru; `package-lock.json` pin versi).
- **Renderer**: WebGL2 dengan fallback WebGL1 otomatis OGL; alpha transparan; DPR ≤1.5.
- **Geometry**: custom lathe — profil tertutup 23 titik (outer wall → rim → inner wall) × 96 segmen radial = 2.208 vertex; normal dari tangent profil (outward luar, inward dalam); uv.y = panjang busur kumulatif ternormalisasi; `Uint16` index; winding CCW dari luar (fix audit — lihat §K).
- **Shader model**: GLSL ES 1.00 `mediump`; seluruh pencahayaan di **view space** konsisten (kamera = origin) — menghilangkan ketergantungan `cameraPosition` bawaan OGL yang pada 1.0.11 tidak pernah ter-set (`uniform3fv` menerima Vec3 object → INVALID_VALUE; temuan audit §K).
- **Fresnel**: `pow(1 - dot(N,V), uFresnelPower=2.2)` pada permukaan front (cullFace BACK, komposit deterministik).
- **Chromatic edge**: variasi power per channel (R ×0.86, G ×1.0, B ×1.18) → fringe tipis cobalt/navy di rim; **bukan klaim refraksi fisik** (tanpa environment map).
- **Monogram watermark**: overlay SVG (§12.2 pilihan resmi spek) — texture path dihapus setelah audit menemukan rasterisasi alpha SVG tidak deterministik (menghasilkan quad semi-opaque). Overlay: path identik asset, opacity 0.16, fade-in 900ms setelah ready, mengikuti area body vessel.
- **Particle budget**: 48 partikel; posisi/seed/scale deterministic (mulberry32 seed 20261101); drift dihitung di vertex shader dari `uTime`+seed (nol update buffer/alokasi per frame); circular soft mask `gl_PointSize` clamp 1–7px; opacity lambat 0.15–0.8 tanpa flicker.
- **Parallax**: `pointermove/pointerleave` pada wrapper saja; hanya `(pointer: fine)`; target ±0.16/±0.1 rad + micro-translate; lerp smoothing 0.06–0.08 dengan objek reuse (tanpa alokasi per frame); idle breathing sin sangat halus (±0.02 rad).
- **Renderer disposal** (API 1.0.11 diverifikasi dari node_modules): `Geometry.remove()` + `Program.remove()` dipanggil; Texture tidak dipakai; `WEBGL_lose_context.loseContext()` tepat satu kali pada dispose final **hanya bila context benar-benar pernah dibuat** (referensi gl diambil sebelum release — tanpa `getContext` ulang); tanpa `renderer.destroy()` (tidak ada di OGL).

## G. Lifecycle and Cleanup

- **`astro:before-swap`**: satu listener module-level (terpasang sekali) → `active.cancel()` → token `cancelled=true`, cancel idle/rAF schedules, stop RAF, release GPU resources (`Geometry.remove()`, `Program.remove()`), `loseContext()` sekali (hanya jika context pernah dibuat), lepas listeners/observers, hapus registry refs, kembalikan `.is-webgl-ready`/`data-webgl-state` (fallback tampil, DOM lama masih tersedia).
- **`motionRegistry.webgl` / `rafLoops`**: `trackWebGLContext(disposeRef)` + `trackRafLoop(rafStop)`; refs di-`delete()` saat dispose manual final agar Set tidak menahan closure; `cleanupMotionRegistry()` after-swap tetap backstop — semua stop/dispose **idempoten** (dipanggil dua kali = no-op).
- **RAF**: satu loop; stop saat offscreen/hidden/disposed/context-lost; resume guard penuh.
- **ResizeObserver**: ukuran wrapper; zero-size guard; anti-loop (canvas absolute, CSS-sized).
- **IntersectionObserver**: threshold 0.01 pada wrapper.
- **Context loss**: listener `webglcontextlost` tanpa `preventDefault` → stop RAF, fallback tampil, dispose final (fallback-only strategy, tanpa retry loop).
- **Async import race** (LC06): hasil import yang resolve setelah before-swap ditolak oleh token + state machine — terbukti test: navigasi cepat saat import di-delay 2s → 0 context di halaman tujuan.
- **Temporary dispose** (viewport ≤700px / reduce aktif mid-session): GPU dibuang, fallback tampil, **listeners MQL tetap terpasang** untuk re-init satu instance saat kondisi kembali layak (fix audit — see §K).

## K. Known Limitations & Temuan Audit yang Diperbaiki

Temuan selama implementasi (semua diperbaiki in-scope, terdokumentasi sebagai bukti pengujian, bukan jalan pintas):

1. **`cameraPosition` OGL 1.0.11 tidak pernah ter-set** — `Mesh.draw` mengirim Vec3 object ke `uniform3fv` (butuh sequence) → uniform tetap (0,0,0) → fresnel terbalik (vessel solid). **Solusi**: seluruh pencahayaan dipindah ke view space (kamera = origin) — lebih murah dan tanpa uniform rawan.
2. **Winding lathe terbalik** — tri (a,c,b) = CW dari luar → `cullFace: BACK` membuang permukaan depan. **Solusi**: winding dibalik (a,b,c / b,d,c), CCW dari luar.
3. **Double-sided alpha banding** — akumulasi front+back tanpa sort menghasilkan band tak menentu. **Solusi**: single front pass (komposit deterministik) + interior depth via gradient UV; sesuai spek §11.4 ("uji overdraw dan artefak front/back face").
4. **Watermark texture tidak deterministik** — rasterisasi alpha SVG per-browser menghasilkan quad semi-opaque. **Solusi resmi spek §12.2**: overlay SVG dengan path identik; seluruh jalur texture dihapus (zero unused uniforms — §22.4).
5. **Temporary dispose sempat melepas MQL listeners** → re-init resize mati. **Solusi**: listeners hanya dilepas pada dispose final.
6. **`getContext` ulang di dispose final menciptakan context yatim** ketika context belum pernah dibuat (terdeteksi via instrumen LC06). **Solusi**: loseContext dari referensi gl yang disimpan, hanya jika ada.

Known limitations yang tersisa (jujur):
- Watermark overlay statis terhadap vessel yang ber-breathing/parallax (amplitudo ≤10px; kontras rendah — tidak terlihat mengganggu).
- Chromatic edge adalah stylized RGB-power separation, bukan refraksi fisik (sesuai §11.3, tanpa env map).
- SwiftShader headless tidak merepresentasikan kualitas visual GPU nyata 1:1; screenshot adalah bukti struktural (silhouette, transparansi, rim, watermark, particles), bukan referensi warna final.
