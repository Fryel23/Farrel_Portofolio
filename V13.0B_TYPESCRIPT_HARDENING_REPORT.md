## 2. Audit Runtime, Compiler & Strategi Kompatibilitas Node.js

1. **Dukungan TypeScript Native pada Node.js `v24.18.0`:**
   - Node.js `v24.18.0` mendukung eksekusi berkas `.ts` secara native melalui *type stripping* (`process.features.typescript === 'strip'`).
   - Modul `.ts` yang berisi sintaks TypeScript erasable (`export type`, `export interface`, anotasi parameter/return, `as const`) dapat diimpor langsung oleh skrip Node `.mjs` maupun dibundle oleh Astro/Vite.
2. **Ketersediaan `typescript` dan `@astrojs/check` pada Lockfile V12.3:**
   - Sesuai catatan spesifikasi B.1 poin 3, paket `typescript` dan `@astrojs/check` tidak terpasang pada `node_modules` arsip V12.3, dan lingkungan sandbox bersifat offline (tanpa akses jaringan keluar).
   - Oleh karena itu, tidak ada dependency baru yang ditambahkan ke `package.json`.
3. **Matriks Keputusan Migrasi Ekstensi vs JSDoc + `// @ts-check`:**
   - Skrip pengujian regresi (`scripts/test-lab-core.mjs`, `scripts/test-csv-explorer.mjs`, `scripts/test-content-integrity.mjs`) dan pipeline build data (`scripts/data/build-cirebon-dataset.mjs`), serta daftar `sourceFiles` pada Fase C, mengimpor dan memverifikasi path eksplisit berekstensi `.js` (`src/scripts/lab/core/aqi-calculator.js`, `src/scripts/lab/shared/stats.js`, `src/scripts/lab/shared/csv-parser.js`, `src/scripts/lab/shared/csv-analysis.js`, `src/scripts/lab/workers/csv-worker.js`).
   - Sesuai pedoman B.1 ("TypeScript untuk modul yang dibundle Astro/Vite dan JavaScript/JSDoc untuk modul yang wajib dieksekusi raw Node") serta Gate 13 ("Tidak ada file ganda atau modul unused"), modul kontrak tipe dan modul baru V13 ditulis dalam `.ts`, sedangkan modul `.js` yang diimpor langsung oleh raw Node ESM dipertahankan pada path `.js` kanonisnya dengan `// @ts-check` dan `@typedef {import('.../*.ts')}` penuh.

## 5. Known Limitations

1. **Absennya Paket CLI `typescript` (`tsc`) dan `@astrojs/check` di Lingkungan Sandbox Offline**
   - **Ringkasan masalah:** Lockfile baseline V12.3 tidak menyertakan paket `typescript` maupun `@astrojs/check`, dan lingkungan eksekusi sandbox tidak memiliki akses jaringan untuk mengunduh paket npm eksternal.
   - **Dampak pengguna atau sistem:** Pemeriksaan sintaks `.ts` dan validasi kontrak dijalankan melalui parser native TypeScript Node `v24.18.0`, compiler Vite/esbuild saat `astro build`, serta suite pengujian kontrak runtime `scripts/test-v13-ts-parity.mjs`, bukan melalui perintah CLI `tsc --noEmit` mandiri.
   - **Mengapa tidak diinstal pada fase ini:** Penambahan paket memerlukan akses jaringan npm registry yang dibatasi oleh sandbox.
   - **Status Blocker:** Non-blocker (seluruh kontrak tipe, struktur payload, dan paritas digest telah diverifikasi melalui `test-v13-ts-parity.mjs` dan `npm run build`).
   - **Syarat penyelesaian:** Ketika dijalankan pada mesin dengan akses registry npm, `npm i -D typescript @astrojs/check` dapat ditambahkan untuk mengaktifkan `astro check`.
   - **File/Test terkait:** `package.json`, `tsconfig.json`, `scripts/test-v13-ts-parity.mjs`.
