### Metodologi ISPU (D09)

- **Formula:** `I = ((Ia − Ib) / (Xa − Xb)) × (X − Xb) + Ib` (P.14/2020).
- **Tabel terverifikasi:** SO₂ (0-52→0-50; >52-180→51-100; >180-400→101-200; >400-800→201-300; >800-1200→301-500) dan NO₂ (0-80; >80-200; >200-1130; >1130-2260; >2260-3000) · **diverifikasi dan disediakan eksplisit oleh pemilik data**. PM2.5 dari lampiran spek V12.0 (6 pita hingga 500.4). PM10/O₃/CO/HC **sengaja tidak diimplementasikan** (belum terverifikasi sumber primer) → status `unsupported-parameter`, bukan angka karangan.
- **Tafsiran kontinu** ">52–180" dipakai agar tidak ada celah antar pita (uji: 52→50, 52.000001→51.0000x, 180→100, tanpa overlap/gap · spec §7.2).
- **Rounding:** konsentrasi tidak dibulatkan sebelum interpolasi; sub-indeks disimpan 4 desimal; ISPU final dibulatkan ke integer terdekat.
- **Basis waktu:** data = agregat tahap (sumber tidak melaporkan basis); periode referensi tabel P.14/2020 untuk SO₂/NO₂ = **24 jam** (keputusan domain final yang dikonfirmasi pemilik data dari Lampiran I; B7). Periode tabel 24 jam tidak otomatis menjadikan observasi sumber rata-rata 24 jam. Jalur eksplisit `allowBasisMismatch:true` → seluruh sub-indeks tercatat `basisMatched:false` dan diberi label "terderivasi" di seluruh UI (aturan spek 11, D10, D11 dipenuhi · tidak ada klaim ISPU resmi berbasis 24 jam).
- **Contoh terverifikasi:** PERUMNAS GUNUNG 2021 T-II: SO₂ 83,9 → 63,21; NO₂ 109,31 → 62,97; ISPU 63 (Sedang), dominan SO₂. Contoh resmi spek PM2.5 31,4 → 70,53 (pita 51–100) → 71; catatan selisih konvensi 69,92 (peta kontinu 50–100) didokumentasikan di methodology §9 · selisih <1 ISPU.

## I. KNOWN LIMITATIONS

1. **ISPU = derivasi dua parameter** (SO₂, NO₂, basis tahap) · bukan ISPU resmi tujuh parameter; PM10/PM2.5/O₃/CO/HC tidak diukur sumber.
2. **Basis waktu per tahap tidak dilaporkan sumber** → semua sub-indeks berstatus estimasi terderivasi (`basisMatched:false`). Periode referensi tabel ISPU untuk SO₂/NO₂ adalah **24 jam** (keputusan domain final B7, dikonfirmasi pemilik data dari Lampiran I P.14/2020); periode tabel tidak otomatis menjadikan observasi sumber rata-rata 24 jam. Limitasi tahun-spesifik (nol serentak 2023, duplikat 2024, parsial 2025) dipisahkan dari limitation source-wide (C9) dan hanya muncul pada tahun terkait.
3. **Satuan µg/Nm³** tidak dikonversi (kondisi referensi tidak disediakan); koordinat lokasi tidak tersedia → null.
4. **2025 parsial** (4 lokasi, TAHAP I); beberapa lokasi tidak diukur setiap tahun → gap.
5. **Nol serentak 2023** (6 grup) kemungkinan berarti tidak terukur · tidak dapat diverifikasi; dipertahankan sebagai valid nol + limitation.
6. **Duplikat NO₂ 2024** (1 grup) · first-occurrence + duplicates tersimpan; dugaan typo tahap tidak diubah.
7. **Lisensi sumber unverified**; URL portal persis tidak diverifikasi dari lampiran.
8. **Region pembanding belum ada** · sengaja; menunggu data terverifikasi (Jawa Barat DLH open data adalah kandidat).
9. **Contoh resmi PM2.5 31,4** → 70,53 (71) vs konvensi 69,92 (70) · selisih konvensi pita didokumentasikan di methodology §9.
